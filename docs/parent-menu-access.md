# 无链接父菜单授权

原问题：/api/manager/menu/fetch/valid 使用 route 非空作为有效菜单条件，导致目录菜单无法在权限分配页选择。

修复：有效菜单按 is_enabled=true 判断，包含无链接目录；停用菜单不再可分配。
“经由用户分配”和“经由权限分配”都保留目录记录，并显示“目录菜单（无链接）”。空目录没有跳转链接。

使用方式：在“权限分配 → 经由用户分配”中选择父目录，为用户开启或关闭访问。也可通过“经由权限分配”注册目录对应权限并授权。修改分配需要既有 menu.permissionManagement.update；读取需要 menu.permissionManagement.read。

父目录和子页面分别授权。授予目录不自动授予子页面或业务接口权限；撤销父目录后，其下页面不会通过该目录在侧栏显示，但子页面原有授权不被删除，API权限保持独立校验。
撤销某项页面权限不会取消独立的用户直接授权；使用“经由用户分配”关闭访问时，会同时清理该用户在该菜单下的页面授权。

不需要新增菜单、权限码或修改数据库。后端重启后，刷新浏览器加载最新列表与侧栏。

验证：H2 查询覆盖无链接父目录、正常页面、停用目录和停用页面；前端交互覆盖目录注册、只授权选中的父目录而不连带授权子页面。
